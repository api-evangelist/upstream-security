# Upstream Security

> Upstream Security is a cloud-based automotive and smart-mobility cybersecurity company. Its purpose-built vehicle data platform delivers Cyber XDR (detection and response) for connected vehicles, runtime AI and API security, proactive quality detection, and advanced analytics, alongside AutoThreat PRO threat intelligence and Vehicle Security Operations Center (vSOC) services for OEMs, Tier 1/2 suppliers, fleets, insurers, and smart-mobility/IoT operators.

Upstream publishes no public developer portal or API reference; the platform is
sold as an enterprise SaaS with demo-based onboarding. This file was generated
by API Evangelist from the public website surface.
